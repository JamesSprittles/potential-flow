# Build your own potential flow

An interactive sandbox for two-dimensional potential flow: drop sources, sinks,
vortices and dipoles into a uniform stream and watch the flow rearrange itself.
Streamlines, equipotentials, stagnation points, the dividing streamline, the
pressure field and the forces are all solved live from the complex potential.

**Live: https://jamessprittles.github.io/potential-flow/**

One self-contained HTML file. No build step, no dependencies, no network calls --
KaTeX and the two fonts it needs are inlined. It runs entirely in the browser and
works offline once loaded. Touch and keyboard are both supported.

Built for the third-year Fluid Dynamics module (MA3D1) at the University of
Warwick by [James Sprittles](https://warwick.ac.uk/fac/sci/maths/people/staff/sprittles/).
